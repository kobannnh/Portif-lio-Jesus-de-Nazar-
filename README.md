# Portif-lio-Jesus-de-Nazar-
Este site é um trabalho escolar e pessoal que apresenta Jesus Cristo sob aspectos históricos, religiosos e culturais. Aborda sua vida, ensinamentos e importância em outras religiões. Utiliza textos bíblicos, vídeos e imagens para fortalecer a fé e o conhecimento com respeito às diferentes crenças.
